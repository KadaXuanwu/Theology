# Description
A quantity that is not zero but is smaller in size than any finite number. John L. Bell's entry puts it as "while not coinciding with zero, is in some sense smaller than any finite number".[^bell-sep] In nonstandard analysis a hyperreal number is infinitesimal if its absolute value is less than 1/(n+1) for every natural number n.[^bell-sep] A positive one is greater than zero yet smaller than every positive fraction 1/n.[^bell-sep]
