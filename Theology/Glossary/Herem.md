# Description
The status of "that which is separated from common use or contact", either as an abomination to God or as consecrated to him.[^ej-herem] In war it meant devoting the enemy to God by killing the population.[^ej-herem] The same word later names a rabbinic excommunication, which is a different sense.[^ej-herem]
