# Description
An argument that establishes a claim by showing that denying it leads to something unacceptable. Nicholas Rescher's entry defines it as a method that "seeks to establish a contention by deriving an absurdity from its denial".[^rescher-iep] In the strict sense the absurdity is a self contradiction; in the looser senses it is a falsehood or an implausible result, and the entry counts those as reductio too.[^rescher-iep]
