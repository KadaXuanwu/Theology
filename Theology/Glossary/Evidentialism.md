# Description
The thesis that a belief is justified only when the believer's evidence supports it. Daniel Mittag states it as "Person S is justified in believing proposition p at time t if and only if S's evidence for p at t supports believing p".[^mittag-iep] Peter Forrest calls it "the initially plausible position that a belief is justified only if 'it is proportioned to the evidence'".[^forrest-sep] In the epistemology of religion it is applied to belief in God.[^forrest-sep] There "evidence" usually means, in Kelly James Clark's words, "the kind of propositional evidence one might find in a theistic argument and not the kind of experiential evidence typically thought to ground religious belief".[^clark-iep] [[Reformed epistemology]] rejects evidentialism in this sense.[^bolos-scott-iep]
