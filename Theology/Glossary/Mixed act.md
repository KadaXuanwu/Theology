# Description
An act done from fear of a greater evil, such as throwing cargo overboard in a storm, which the agent chooses at the moment but would not choose for its own sake. Tim O'Keefe's *Stanford Encyclopedia* entry describes Aristotle's "mixed actions" as "ones that are done knowingly but unwillingly". It adds that "such actions, says Aristotle, are voluntary, and the agent is responsible for them".[^okeefe-2024] Aquinas takes up the same case and calls such acts "voluntary simply, but involuntary in a certain respect".[^aquinas-st-i-ii-6]
