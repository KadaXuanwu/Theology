# Description
The error of taking a lack of proof that a claim is true as proof that it is false, or a lack of proof that it is false as proof that it is true. Bradley Dowden's entry files it as the appeal to ignorance and says the fallacy "occurs in cases where absence of evidence is not good enough evidence of absence".[^dowden-iep] The same entry says the reasoning is proper only if the search was thorough and the thing, if it existed, would have left a discoverable proof.[^dowden-iep]
